## 📁 Repository Structure

### 📌 [Presentation III](./Presentation%20III/) — Online Course Learning Progress Management System
A full-stack relational database management application prototype built with **Python (Flask)**, **MySQL 9.7**, and a warm minimalist **HTML5/CSS3/JavaScript** user interface.

- **[`Presentation III/app.py`](./Presentation%20III/app.py)**: Flask backend application server & RESTful API engine
- **[`Presentation III/init_db.sql`](./Presentation%20III/init_db.sql)**: Complete MySQL DDL schema (8 normalized tables), foreign key cascades, and initial datasets
- **[`Presentation III/report.md`](./Presentation%20III/report.md)**: Hardcore technical project report & architectural specification
- **[`Presentation III/README.md`](./Presentation%20III/README.md)**: Presentation III module documentation & local setup instructions
- **[`Presentation III/templates/`](./Presentation%20III/templates/)**: Semantic HTML5 templates
- **[`Presentation III/static/`](./Presentation%20III/static/)**: Custom CSS design system & JavaScript event handlers
